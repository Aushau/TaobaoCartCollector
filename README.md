# 购物车采集器 / TaobaoCartCollector

Chrome 扩展，采集淘宝/天猫/京东购物车商品信息（价格、促销标签、规格、数量）。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 开启"开发者模式"
3. "加载已解压的扩展程序"，选择本项目目录

## 使用方法

- 打开淘宝/天猫/京东购物车页面，自动采集
- 点击扩展图标查看购物车商品列表
- 点击商品卡片跳转到商品详情
- 商品详情页可采集单品信息到"已采集"标签

## 文件说明

| 文件 | 功能 |
|------|------|
| `cart.js` | 购物车页面 content script，提取价格/促销/规格 |
| `content.js` | 商品详情页 content script，采集单品信息 |
| `popup.html` | 弹窗 UI，购物车 + 已采集双标签 |
| `popup.js` | 弹窗渲染逻辑 |
| `manifest.json` | 扩展配置 |
